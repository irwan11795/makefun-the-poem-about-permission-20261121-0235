A short poem about agency: the power to ask and to be given.

The program (`main.py`, Python 3.13, stdlib only) writes the entry text to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, `/output`, `./output`, or the system temp dir as fallback), deterministically.
